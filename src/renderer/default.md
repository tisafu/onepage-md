# 欢迎来到一页

> 这里没有仓库、没有文件树、没有知识图谱大转盘。  
> 这里只有你眼前这一页，安安静静，打开就读。

你好，我是 **一页 OnePage**，一个很轻的 Markdown 阅读窗口。

我适合用来做这些事：

- 快速打开一份 `.md` 文档
- 看排版好的中文 Markdown
- 阅读带表格、引用、代码块、图片的长文
- 临时检查一份文档长什么样
- 不想启动 Obsidian、VS Code、浏览器大队伍的时候，叫我一下

## 怎么打开文件

点击右上角的 **打开新文件**，选择一份 Markdown，就可以开始阅读。

打开以后，我会显示：

- 左侧目录
- 正文阅读区
- 当前文件名和路径
- 字数、大小、修改时间

## 我不会做什么

放心，我不会偷偷变成一个复杂笔记软件。

我不会：

- 创建 vault
- 扫描你的文件夹
- 管理附件
- 维护数据库
- 给你画知识图谱
- 在你只是想看一页文档时，突然搬出一整套工作台

## 支持哪些 Markdown

### 标题

从 `# 一级标题` 到 `###### 六级标题` 都可以。

### 引用

> 一级引用会贴齐正文左边界，只保留一条安静的左线。

> 如果你继续嵌套：
>
> > 我才会往里缩一点点，表示层级。

### 表格

| 功能 | 状态 | 小备注 |
| --- | --- | --- |
| GFM 表格 | 支持 | 适合看评测表 |
| 代码块 | 支持 | 不抢戏 |
| 图片 | 支持 | 远程图如果被服务器拦截，我也没法硬闯 |
| 自动目录 | 支持 | 标题会自动进入左侧目录 |

### 代码块

```js
const page = "一页";
console.log(`${page}：只读当前文档，不打扰。`);
```

## 一点点使用建议

如果你在写文档，我建议这样搭配：

- 用喜欢的编辑器写 Markdown
- 用一页预览阅读效果
- 觉得哪里不舒服，就调整 CSS
- 保存，然后继续读

## 小结

一页的原则很简单：

> 一页就是一页。  
> 打开一份文档，把它读舒服。
